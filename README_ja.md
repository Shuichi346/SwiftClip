# SwiftClip

SwiftClip は、macOS 26.0 以降向けのローカルファースト設計による macOS メニューバー用クリップボードマネージャー兼スニペットランチャーです。Clipy の UI と使いやすさにインスパイアされています。クリップボードの履歴、再利用可能なスニペット、スニペット添付ファイル、設定、インポート/エクスポートデータをユーザーの Mac 上に保存し、アクセシビリティ権限が付与されると、選択した履歴またはスニペット項目を直前にフォーカスされていたアプリにペーストします。Swift 6、SwiftUI、AppKit で構築されており、Clipy 互換の XML インポート/エクスポート、グローバルショートカット、アプリ固有のキャプチャルール、テキストと添付ファイルを混在させたスニペットのペーストをサポートしています。

## UI プレビュー

<img src="GitHub Documents/swiftclip-snippet-editor.png" alt="SwiftClip スニペットエディタウィンドウ" width="480">

スニペットエディタはサイドバーでフォルダとスニペットを整理し、詳細ペインで編集可能なスニペットの詳細、有効化、ショートカット記録、大きなコンテンツエディタを提供します。

## 機能

- 設定可能な項目数制限とタイトル長を持ち、通常のペースト用のリッチコンテンツを保持しながら RTF/RTFD の内容を読める形で表示するメニューバーのクリップボード履歴。
- 再利用可能なスニペットフォルダと、項目ごとの有効化設定が可能なスニペット項目。
- 設定可能なグローバルショートカットから開くスタンドアロンの履歴/スニペットポップアップ。
- ドラッグ＆ドロップによるフォルダ順序変更・スニペット順序変更・フォルダ間スニペット移動が可能なスニペットエディタ。
- ローカルファイル、画像、動画に対応したスニペット添付ファイル（任意のプロンプトテキスト付き）。
- 選択したアプリに対してテキストを先に、添付ファイルを後にペーストできる混在スニペットペーストのサポート。
- 有効にすると、テキストとして扱える履歴項目をプレーンテキストに変換し、スニペットは添付ファイルを除いたテキストのみをペーストする**常にプレーンテキストとしてペースト**設定。
- スニペット移行のための Clipy 互換 XML インポートおよびエクスポート。
- スニペット ID、有効化状態、順序、ショートカット、管理された添付ファイルを保持し、ライブラリの置換または復元操作前に復元可能な `.swiftclipbackup` 安全バックアップ。
- プレーンテキスト、RTF、RTFD、ファイル URL、URL、PDF、画像に対応したフォーマットフィルタリング。
- 標準アプリピッカーで選択できる、キャプチャ除外アプリおよび混在スニペットペーストアプリのアプリ固有設定。
- より大きなクリップボードペイロード向けに個別 blob ファイルを使用したローカル JSON メタデータストレージ。
- Service Management によって支援されたログイン時起動設定。

## 技術スタック

- Swift 6
- SwiftUI および AppKit
- 設定スキャフォールディング向けの SwiftData モデル定義（現在のストアはローカル JSON ファイルで管理）
- KeyboardShortcuts 3.0.1 以降の互換リリース

- macOS 26.0 以降

- 自動ペーストインジェクションのためのアクセシビリティ権限

## ソースからのビルド

Xcode で `SwiftClip.xcodeproj` を開き、`SwiftClip` スキームをビルドしてください。

コマンドラインでのデバッグビルドの場合：

```sh
xcodebuild -project SwiftClip.xcodeproj \
  -scheme SwiftClip \
  -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /private/tmp/swiftclip-derived \
  CODE_SIGN_IDENTITY="-" \
  CODE_SIGNING_REQUIRED=NO \
  CODE_SIGNING_ALLOWED=NO \
  build
```

ローカルでのビルドと起動確認の場合：

```sh
./script/build_and_run.sh --verify
```

## テスト

完全なテストスイートを実行するには：

```sh
xcodebuild -project SwiftClip.xcodeproj \
  -scheme SwiftClip \
  -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /private/tmp/swiftclip-derived \
  CODE_SIGN_IDENTITY="-" \
  CODE_SIGNING_REQUIRED=NO \
  CODE_SIGNING_ALLOWED=NO \
  test
```

47 のテストは、クリップボードのキャプチャとペーストの正確性、リッチテキスト履歴の読みやすい表示、プレーンテキストペーストの方針、blob パスの安全性、履歴と設定の永続化、順序付き JSON 書き込み、Clipy XML インポート/エクスポート、完全なスニペットバックアップと復元、ショートカットのクリーンアップと移行、管理された添付ファイル、メニュータイトルの書式設定、スニペットの並び替えをカバーしています。

## 使い方

1. SwiftClip を起動します。
2. SwiftClip が直前にフォーカスされていたアプリに選択した項目をペーストするには、プロンプトが表示されたときにアクセシビリティ権限を付与してください。
3. メニューバーアイテムを使用してクリップボード履歴、スニペット、設定、アプリアクションを閲覧します。
4. 設定でショートカットを設定します。
5. スニペットエディタを開いて、フォルダの作成、スニペットの編集、ファイルの添付、フォルダまたはスニペットのショートカット割り当て、Clipy XML のインポートまたはエクスポート、SwiftClip バックアップの復元を行います。

## スニペットのインポート・エクスポート・バックアップ

- **エクスポート**は、選択した場所に Clipy 互換の XML ファイルを書き出します。これは移行を目的としており、フォルダ名、スニペット名、テキストコンテンツ、順序が含まれます。SwiftClip の ID、有効化状態、ショートカット、添付ファイルは含まれません。
- **インポート**は、XML の内容を現在のライブラリに追加するか、ライブラリを置き換えることができます。SwiftClip は置き換えが始まる前に完全な安全バックアップを作成します。追加インポートではバックアップは作成されません。
- **バックアップを復元**すると、`.swiftclipbackup` パッケージから現在のスニペットライブラリが置き換えられます。パッケージには ID、有効化状態、順序、フォルダおよびスニペットのショートカット、SwiftClip が管理する添付ファイルが保持されます。SwiftClip は復元を開始する前に現在のライブラリもバックアップします。

安全バックアップは `~/Library/Application Support/SwiftClip/Backups` に保存されます。自動的に削除されないため、古いバックアップパッケージは手動で削除するまで残ります。

## 設定

SwiftClip の設定はローカルに JSON として保存され、メニューバーアプリから利用できます。

- **一般**: ログイン時に起動、履歴項目またはスニペットを選択後に自動ペースト。
- **メニュー**: 表示番号とメニュータイトルの長さ。
- **フォーマット**: SwiftClip が履歴としてキャプチャするペーストボードフォーマット。
- **アプリ**: クリップボードキャプチャから除外するアプリと、テキストを先に・添付ファイルを後にという 2 回のペースト操作で混在スニペットを受け取るべきアプリのための**混在スニペットペーストアプリ**。
- **ショートカット**: メインポップアップ、スニペットエディタ、設定、履歴クリアアクションのグローバルショートカット。
- **拡張機能**: **常にプレーンテキストとしてペースト**。無効の場合は、リッチテキスト履歴とスニペット添付ファイルを従来どおりの形式でペーストします。有効の場合は、テキストとして扱える履歴をプレーンテキストで書き込み、スニペットは添付ファイルを除いたテキストのみをペーストします。テキスト表現を持たない画像および PDF の履歴項目は、この設定が有効な間はペーストされません。

アプリ一覧は内部ではバンドル識別子を保存していますが、設定 UI はインストール済みのアプリを解決し、わかりやすさのために `Firefox.app` などの名前を表示します。アプリを解決できない場合、SwiftClip はバンドル ID を表示するようにフォールバックします。

## ローカルデータ

SwiftClip はアプリデータを以下に保存します：

```text
~/Library/Application Support/SwiftClip
```

クリップボードの blob は JSON 履歴インデックスとは別に保存されるため、大きなバイナリペイロードがメタデータファイルを肥大化させることはありません。

現在のローカルファイルには以下が含まれます：

- `Preferences.json`
- `History.json`
- `Snippets.json`
- `Blobs/`
- `SnippetAttachments/`
- `Backups/`

`SnippetAttachments/` にはスニペットに添付されたファイルの管理されたコピーが含まれます。`Backups/` には XML 置き換えインポートおよびバックアップ復元前に作成されたバージョン管理された `.swiftclipbackup` パッケージが含まれます。

## プロジェクト構成

```text
SwiftClip/
  App/              アプリのライフサイクルと環境の配線
  Clipboard/        クリップボードのキャプチャ、履歴、blob ストレージ、ペーストサポート
  MenuBar/          メニューバーおよびスタンドアロンポップアップメニュービルダー
  Onboarding/       権限プロンプト UI
  Preferences/      設定ストアと設定タブ
  SnippetEditor/    スニペットエディタウィンドウ、アウトライン、ツールバー、詳細ペイン
  Snippets/         スニペットモデル、ストア、Clipy XML コーデック、バックアップサポート
  Support/          共有ログ、ローカライズ、エラー、ファイルの場所
SwiftClipTests/     永続化、ペースト動作、バックアップ、ショートカット、順序付けの XCTest カバレッジ
script/             ローカルビルドおよび起動ヘルパー
```

## トラブルシューティング

- パッケージの解決に失敗した場合は、Xcode で `SwiftClip.xcodeproj` を開いてパッケージを解決するか、ネットワークアクセスがある状態で `xcodebuild -list -project SwiftClip.xcodeproj` を再実行してください。
- 自動ペーストが機能しない場合は、システム設定のアクセシビリティで SwiftClip が承認されていることを確認してください。
- テキストと添付ファイルを混在させたスニペットがチャットやアップロードフィールドで一部しかペーストされない場合は、そのアプリを**設定 → アプリ → 混在スニペットペーストアプリ**に追加してください。
- Xcode の警告 `Metadata extraction skipped. No AppIntents.framework dependency found.` はこのプロジェクトで既知の問題であり、ビルドの失敗ではありません。
